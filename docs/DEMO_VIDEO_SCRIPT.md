# LX Family: 75-second product demo

Use the public demo only (`Demo` / `demo`) and record no personal family data.
This is a short, real-product walkthrough for a release post, store listing or
project page. Keep the capture at 16:9, show the cursor/touches only where they
make an interaction clearer, and add captions instead of a synthetic voice.

| Time | Show | Caption |
| --- | --- | --- |
| 0–6 s | LX Family logo and profile bubbles | `LX Family · Private Family OS` |
| 6–17 s | Select the child profile | `A space that children can actually use` |
| 17–29 s | Child dashboard: routines, missions and stars | `Routines, rewards and parent approval` |
| 29–40 s | Switch to an adult, show today and shared calendar | `One calm overview for the whole household` |
| 40–50 s | Create/open a task and its approval state | `Children finish tasks. Adults confirm them.` |
| 50–59 s | Open Family Cloud and an uploaded photo | `Family files, directly in LX` |
| 59–68 s | Show Android app or a reminder | `Browser and Android notifications` |
| 68–75 s | Return to profile bubbles, then the self-hosted install page | `Your server. Your family data. LX Family.` |

## Publishing notes

- State clearly that LX Family is self-hosted and does not operate a central
  family service.
- Use only the public demo or deliberately created test data.
- Mention that AI-assisted tools were used during development when a community
  requires that disclosure.
- Link to the repository, the demo and the platform installation guide.
