# LX Family Planner 1.13.1

LX zeigt jetzt direkt, wo das öffentliche Projekt zu finden ist. Wer den
Familienplaner gerne nutzt, kann das Repository ansehen, Ideen verfolgen,
mitmachen oder einen GitHub-Stern dalassen.

## Neu in dieser Version

- gut sichtbare, ruhige GitHub-Einladung auf der Familienauswahl
- dauerhafter Projektlink in der Familienverwaltung
- verständliche Beschriftung ohne technische Vorkenntnisse
- passende Darstellung in hellen und dunklen Themen
- responsive Bedienung auf Handy, Tablet und Desktop

Die Links öffnen ausschließlich:

```text
https://github.com/laxxx-lab/lx-family-planner
```

Es werden dabei keine Familieninhalte, Einstellungen oder Zugangsdaten an
GitHub übertragen. Alle vorhandenen Daten bleiben beim Update erhalten.

---

LX Family Planner now links directly to its public GitHub repository from the
family selection screen and family settings. Existing family data and settings
remain unchanged.
