# LX Family Planner 1.18.0

This release adds five new interface languages, fixes dashboard and navigation
bugs from issue #15, and keeps existing family data compatible.

## Five new languages

- French, Spanish, Italian, Dutch and Polish join German and English as full
  interface languages.
- The language picker in the header and on the login screen offers all seven
  languages; any missing translation falls back to English cleanly.
- Dates, currency and the Bring! catalogue use the matching locale per
  language.

## Calendar and dashboard improvements (#15)

- "Today at a glance" and the calendar badge now count only the current day's
  events instead of every upcoming event.
- "My events" starts at the current day, consistent with the tablet view.
- Events assigned to a profile show the assignee names instead of always
  "family event".
- A real week and month calendar grid makes free time slots visible, and
  waste-collection pickups on the same day are bundled into one entry.
- Dashboard widgets open directly on click, and the greeting card is more
  compact on mobile.

## Navigation and stability

- The tab bar no longer shifts when switching, and the last tab stays
  reachable in browsers such as Firefox.
- The Android hardware back button and gesture navigates back inside the app
  instead of exiting it.
- The dashboard studio footer (Reset/Done) no longer gets clipped when the
  conditional picker blocks are shown.
- The "create family" onboarding dialog shows why "Next" is inactive when the
  password is too short or an invite code is required.

## Deutsch

Dieses Release fügt fünf neue Benutzeroberflächen-Sprachen hinzu und behebt
die Dashboard- und Navigationsprobleme aus Issue #15. Französisch, Spanisch,
Italienisch, Niederländisch und Polnisch ergänzen Deutsch und Englisch als
vollständige Sprachen; der Sprachumschalter bietet alle sieben Sprachen an,
fehlende Übersetzungen fallen sauber auf Englisch zurück. „Heute im Blick"
zählt nur noch die heutigen Termine, zugewiesene Termine zeigen die
Profilnamen, eine echte Wochen- und Monatsansicht macht freie Zeitfenster

Tab-Leiste springt nicht mehr beim Wechseln, Androids Zurück-Taste navigiert
in der App, das Ansichtsatelier bleibt vollständig bedienbar, und der
Onboarding-Dialog zeigt, warum „Weiter" inaktiv ist. Vorhandene Familien,
Profile, Termine, Aufgaben, Rezepte, Dateien und Einstellungen bleiben
unverändert erhalten.
