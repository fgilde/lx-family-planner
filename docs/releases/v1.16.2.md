# LX Family Planner 1.16.2

This release adds the notification, wall display and profile permission
improvements requested in the community feedback threads. Existing family data
stays compatible.

## Notifications and wall display

- ntfy is available as an additional, optional push channel alongside Gotify.
- A dedicated, read-only wall display profile exposes only reading and the two
  intended check-off actions, so a shared tablet cannot change settings or
  switch profiles.
- The tablet view asks "who completed this?" with large profile bubbles instead
  of navigating away, so checking off a chore stays fast at a central display.

## Finer profile permissions

- Chores can be marked as shared, so a single completion counts for everyone
  that day while the stars go to the person who actually did it.
- The adult "Tochter (erwachsen)" and "Sohn (erwachsen)" positions receive
  family-admin rights.
- Cloud or mailbox access can be granted per profile independently of the role.
- Switching from an adult to a child profile now immediately closes the cloud
  and parent areas and returns to the dashboard.
- Individual modules such as the mailbox or cloud can be hidden globally for
  the whole family or per profile.

## Calendar, Home Assistant and cloud uploads

- The waste-collection card can be set to always, never, or only a configurable
  number of days before the next pickup.
- The Home Assistant entity list scrolls within a capped height instead of
  collapsing many devices into thin lines, and selecting a device expands the
  "allow control" detail panel.
- Failed cloud uploads now surface the concrete HTTP status code instead of
  failing silently.

## Deutsch

Dieses Release bringt die aus den Community-Feedback-Threads gewünschten
Verbesserungen für Benachrichtigungen, Wanddisplay und Profilrechte. ntfy ist
als zusätzlicher Push-Kanal neben Gotify verfügbar, ein schreibgeschütztes
Wanddisplay-Profil schützt geteilte Tablets, und die Tabletansicht fragt beim
Abhaken mit großen Profil-Bubbles, wer die Aufgabe erledigt hat. Aufgaben
lassen sich als gemeinsam markieren, erwachsene Kinder-Positionen erhalten
Admin-Rechte, und Cloud- oder Briefkasten-Zugriff ist pro Profil frei vergebbar.
Beim Wechsel auf ein Kinderprofil schließen sich Eltern-Bereiche sofort, und
Module lassen sich global oder pro Profil ausblenden. Die Müll-Kachel kann
zeitgesteuert erscheinen, die Home-Assistant-Liste scrollt sauber, und fehl-
geschlagene Cloud-Uploads zeigen den konkreten HTTP-Code. Vorhandene Familien,
Profile, Termine, Aufgaben, Rezepte, Dateien und Einstellungen bleiben
unverändert erhalten.
