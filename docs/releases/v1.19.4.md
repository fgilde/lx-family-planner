# LX Family 1.19.4

## Klarerer Familienkalender

Die Wochenansicht zeigt jetzt den vollständigen Tag von 00:00 bis 24:00 Uhr.
Treffen mehrere Termine gleichzeitig zusammen, bleiben sie auf ihrer echten
Uhrzeit und werden seitlich so getrennt, dass ihre farbigen Ränder erkennbar
bleiben.

Kalenderquellen lassen sich für genau die gewünschten Familienprofile
freigeben. Wenn eine Quellfarbe bereits verwendet wird, weist LX auf eine
mögliche Verwechslungsgefahr hin.

## Verlässlicher Austausch

ICS-Exporte enthalten Endzeit und Enddatum eines Termins. Das macht
zeitgebundene und mehrtägige Termine in anderen Kalendern zuverlässig.

Die Sicherungsverwaltung bleibt auch auf schmalen Ansichten übersichtlich. Der
Dialog für die Server-Adresse lässt die Seite wieder sauber scrollen.

## Android-Build unter Linux

Pop!_OS-, Ubuntu- und andere Debian-basierte Rechner können die Android-
Werkzeuge einmalig mit `bash scripts/setup-android-popos.sh` einrichten.
Anschließend erstellt `npm run build:apk:linux` eine signierte APK, wenn die
passende Firebase-Datei und der bisherige Release-Schlüssel vorliegen.
