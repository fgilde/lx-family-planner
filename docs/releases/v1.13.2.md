# LX Family Planner 1.13.2

Dieses Sicherheitsupdate schützt öffentlich erreichbare LX-Server vor freien
Fremdregistrierungen und einer sichtbaren Liste aller Familienkonten.

## Was sich für Familien ändert

- Auf der Anmeldung werden private Familien nicht mehr aufgelistet.
- Familien geben ihren Familiennamen und das Familienpasswort selbst ein.
- Eine neue Installation erlaubt automatisch genau die erste Familie.
- Danach bleibt die Registrierung geschlossen, sofern der Serverbetreiber sie
  nicht bewusst per Einladungscode öffnet.
- Eine ausdrücklich konfigurierte öffentliche Demo bleibt als eigene
  schreibgeschützte Auswahl erreichbar.
- Neue oder geänderte Familienpasswörter benötigen mindestens zehn Zeichen.

## Hinweise für Serverbetreiber

Sichere Standardeinstellung:

```env
REGISTRATION_MODE=first-family
PUBLIC_FAMILY_DIRECTORY=false
```

Kontrolliert weitere Familien einladen:

```env
REGISTRATION_MODE=invite
REGISTRATION_INVITE_CODE=hier-einen-langen-zufaelligen-code-eintragen
PUBLIC_FAMILY_DIRECTORY=false
```

`REGISTRATION_MODE=open` und `PUBLIC_FAMILY_DIRECTORY=true` sind nur für
bewusst öffentliche Mehrfamilien-Portale vorgesehen.

Das Update ändert oder löscht keine bestehenden Familien, Profile, Termine,
Chats, Cloud-Dateien oder Einstellungen.

---

LX Family Planner 1.13.2 disables public family discovery by default and only
allows the first family to self-register. Existing data remains unchanged.
