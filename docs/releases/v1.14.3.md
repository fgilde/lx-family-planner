# LX Family Planner 1.14.3

Dieses Sicherheitsupdate trennt die öffentliche Demo strikt von Family Cloud
und sämtlichen externen Integrationen.

## Sicherheitskorrekturen

- Demo-Sitzungen erhalten serverseitig keinen Zugriff auf
  `/api/integrations` oder untergeordnete Integrationsrouten.
- Nextcloud-Anmeldedaten, Dateilisten, Inhalte, Ordner und Sicherungen werden
  unabhängig von der sichtbaren Oberfläche mit HTTP 403 verweigert.
- Der Demo-Bootstrap enthält keine Integrationsadressen, Benutzernamen,
  Geräte oder verbundenen Dienste.
- LX provisioniert, synchronisiert und sichert kein Cloud-Konto für die
  öffentliche Demo.
- Cloud-Ansicht, Navigation und Dashboard-Widget sind im Demo-Modus entfernt.
- Regressionstests prüfen mehrere direkte Umgehungsversuche gegen Cloud und
  Home Assistant.

Echte Familienkonten und ihre jeweils getrennten Nextcloud-Speicher bleiben
unverändert.

---

LX Family Planner 1.14.3 denies all integration and cloud access to public
demo sessions while preserving private family data.
