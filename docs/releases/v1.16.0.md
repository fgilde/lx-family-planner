# LX Family Planner 1.16.0

This release adds automatic family birthdays, shared chores, complete recipe
editing, Tandoor and social recipe imports, calm and custom themes, and the
first complete English interface. Existing family data stays compatible.

## Birthdays and calendar

- Profiles can store an optional date of birth.
- Birthdays return automatically as read-only family calendar events.
- Family members are notified one week before and on the birthday.
- Upcoming views show only the nearest birthday per person instead of the
  current and following year at the same time.
- The waste collection card can be shown always, never or only shortly before
  the next collection.

## Shared chores

- One chore can be assigned to several family members.
- Stars go to the person who actually completed the chore.
- A child's completion still requires approval from the adult who created it.
- Tablet mode asks who completed a shared chore using large profile bubbles.

## Recipes

- Ingredients and preparation steps can be created and edited completely.
- Official Tandoor ZIP and JSON exports import recipes and available images.
- RTK recipe files are accepted, including embedded images where available.
- Public Facebook Reel links can be shared from Android or pasted into LX.
- Social imports open as reviewable drafts and are saved only after approval.

## Themes and languages

- Three calm themes without decorative motifs are available.
- Safe custom CSS is stored as a separate theme and never overwrites a built-in
  design.
- German and English can be selected before login and from the application
  header; the device remembers the choice.
- API errors, release notes and web-app manifests follow the selected language.

## Reliability and onboarding

- New families always keep at least one signed-in adult administrator.
- Existing affected families are repaired safely during the database migration.
- The birthday agenda no longer displays two future years at once.
- Android sharing accepts compatible text payloads from more recipe apps.
