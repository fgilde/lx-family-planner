# LX Family Planner 1.15.0

Dieses Funktionsupdate macht den Familienkalender wieder vollständig bedienbar
und ergänzt einen eigenen Stundenplan für Kinder.

## Kalender

- Ein Klick auf eine Kalenderkarte öffnet den Termin wieder zuverlässig.
- Eigene Termine lassen sich vollständig bearbeiten oder löschen.
- Ein Termin kann der ganzen Familie oder mehreren ausgewählten Personen
  gleichzeitig zugeordnet werden.
- Bestehende Termine mit nur einer Person bleiben kompatibel.
- Von der eigenen Familie geteilte Termine werden bei verbundenen Familien
  mit aktualisiert.

## Schule

- Eltern schalten den Schulbereich für jedes Kind einzeln ein oder aus.
- Der Wochenplan bildet Montag bis Freitag ab.
- Pro Schulstunde können Fach, Titel, Stunde, Beginn, Ende, Raum und Lehrkraft
  gespeichert werden.
- Ein einmaliger Unterrichtsausfall wird für das gewählte Datum rot angezeigt
  und kann zurückgenommen werden.
- Vergangene Ausfallmarkierungen werden automatisch bereinigt.

## Mobile Ansicht

- Die drei Aktionen im Rezeptbuch bleiben auch auf schmalen Smartphones
  vollständig sichtbar und bedienbar.

Vorhandene Familien, Profile, Termine, Kalenderquellen, Cloud-Dateien und
Einstellungen bleiben beim Update erhalten.

---

LX Family Planner 1.15.0 restores full calendar-event editing, supports
multi-person events, adds per-child timetables and fixes the mobile recipe
action layout while preserving existing family data.
