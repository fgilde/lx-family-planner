# LX Family 1.18.2

## Your server stays connected

LX Family for Android now stores the selected family server in native Android
preferences. The address is restored before the app starts and existing
WebView settings migrate automatically. Updating the APK therefore no longer
leaves the app without its configured server.

This release also makes fresh self-hosted installations easier and safer:

- Docker creates and persistently stores a strong application secret when an
  administrator did not provide one explicitly;
- the hardened container starts and restarts cleanly with restricted rights;
- an Android update now only uses APK metadata when it belongs to the exact
  APK file delivered by the server, so stale files cannot cause a checksum
  mismatch;
- the Docker image also builds on older Docker installations without BuildKit;
- ready-to-review packages for CasaOS/ZimaOS and Cosmos are included;
- the large FamilyContext has begun moving into smaller focused modules while
  preserving existing family data and behavior.

## Deutsch

Die Android-App speichert den ausgewählten Familienserver jetzt im nativen
Android-Speicher. Die Adresse wird vor dem Start der Oberfläche geladen, und
eine bisher im App-Speicher vorhandene Adresse wird automatisch übernommen.
Nach einem APK-Update muss der Server daher nicht erneut eingetragen werden.

Neue Docker-Installationen erzeugen bei Bedarf selbstständig einen starken
Sicherheitsschlüssel und bewahren ihn geschützt im dauerhaften Datenordner auf.
Der gehärtete Container startet und beendet sich zuverlässig. Zusätzlich sind
fertige Pakete für CasaOS/ZimaOS und Cosmos enthalten. Der APK-Download prüft
außerdem zuverlässig, dass Prüfsumme und tatsächlich geladene Datei identisch
sind; auch ältere Docker-Engines ohne BuildKit werden unterstützt. Familien,
Profile, Termine, Aufgaben, Rezepte, Dateien und Einstellungen bleiben
unverändert.
