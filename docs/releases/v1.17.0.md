# LX Family Planner 1.17.0

This release brings the mobile navigation drawer suggested in issue #14 and
keeps existing family data compatible.

## Mobile navigation drawer

- On phones and tablets in portrait, the horizontal scrolling tab bar is
  replaced by a slide-in drawer opened with the ☰ menu button in the header.
- All navigation entries and their badges are visible at a glance, so nothing
  stays hidden behind a horizontal scroll anymore.
- Picking an entry switches the view and closes the drawer automatically, so
  the chosen screen is immediately visible.
- The drawer also hosts the language, theme, server connection and logout
  actions on narrow viewports, which declutters the header on small screens.
- The header keeps the brand, the menu button, notifications and the profile
  pill on mobile; everything else moves into the drawer.
- Desktop and tablet landscape (from 900 px upwards) keep the familiar
  horizontal tab bar unchanged.

## Deutsch

Dieses Release bringt die aus Issue #14 hervorgegangene mobile Navigation
als ausklappbare Seitenleiste. Auf Handys und Tablets im Hochformat ersetzt
ein über das ☰-Symbol öffnbarer Drawer die bisherige horizontale Scroll-Leiste:
Alle Menüpunkte und Badges sind auf einen Blick sichtbar, nach der Auswahl
eines Punktes schließt die Leiste automatisch, und auch Sprache, Theme,
Server-Einstellungen und Abmeldung sind auf schmalen Bildschirmen dort
untergebracht. Die obere Leiste behält auf dem Mobilgerät nur Marke,
Menübutton, Benachrichtigungen und Profil – alles andere wandert in den
Drawer. Desktop und Tablets im Querformat ab 900 px behalten die gewohnte
horizontale Tab-Leiste. Vorhandene Familien, Profile, Termine, Aufgaben,
Rezepte, Dateien und Einstellungen bleiben unverändert erhalten.
