# LX Family 1.20.0

## Sicher umziehen, entspannt wiederherstellen

Mit diesem Release kann eine gesamte Familie verschlüsselt auf einen neuen,
leeren LX-Family-Server umziehen. Die Umzugsdatei enthält Profile und PINs,
Kalender, Aufgaben, Notizen, Rezepte, lokale Rezeptbilder sowie den
Papierkorb. Die Datei wird mit einer eigenen Passphrase geschützt und ist nur
für den einmaligen Import auf einem noch leeren Server gedacht.

Server- und gerätegebundene Verbindungen wie Push-Geräte, Cloud-, WebDAV-,
CalDAV- und Smart-Home-Verbindungen werden absichtlich nicht mitgenommen.
Sie müssen auf dem neuen Server neu verbunden werden.

Eltern finden zusätzlich einen Familienpapierkorb in der Elternzentrale. Dort
lassen sich einzelne gelöschte Einträge gezielt zurückholen, ohne eine ganze
Sicherung einzuspielen.

## Kalender schneller füllen

Ein Klick auf eine freie Zeit im Wochenkalender bereitet direkt einen
30-Minuten-Termin vor. Wer einen Bereich aufzieht, erhält genau diesen
Zeitraum in der Termineingabe. Überlappende Termine bleiben dabei auf kleinen
wie großen Bildschirmen besser lesbar.

## Ruhiger auf dem Handy

Das Terminformular öffnet auf Touch-Geräten ohne voreingestellten Textcursor.
Die Bildschirmtastatur verdeckt dadurch nicht mehr die Zeitwahl und die
Aktionen.
