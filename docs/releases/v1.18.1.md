# LX Family 1.18.1

## A new product name, with safe updates

LX Family Planner is now presented as **LX Family · Private Family OS**. The
new name describes the project more clearly: it is a private, self-hosted home
for calendars, chores, meals, cloud files, child spaces and everyday family
life.

This is a deliberately compatibility-focused release:

- existing families, profiles, events, chores, recipes, files and settings are
  unchanged;
- the Android application id remains `com.lxfamily.planner`, so the APK
  installs directly over the existing app;
- the Docker image and repository slug remain stable, so the normal safe update
  route continues to work;
- release image metadata no longer points to a developer-specific URL. Every
  self-hosted LX Family installation can use its own local or public address.

## Deutsch

LX Family Planner heißt sichtbar nun **LX Family · Private Family OS**. Der
Name passt besser zu einem privaten, selbst gehosteten Zuhause für Kalender,
Aufgaben, Essen, Cloud-Dateien, Kinderwelten und euren gemeinsamen Alltag.

Dieses Release ist bewusst vollständig update-kompatibel: Familien, Profile,
Termine, Aufgaben, Rezepte, Dateien und Einstellungen bleiben erhalten. Die
Android-Kennung `com.lxfamily.planner`, das Docker-Image und die technische
Repository-Adresse bleiben stabil, damit die neue APK einfach über die
vorhandene App installiert werden kann und die normalen sicheren Updates ohne
Neuinstallation weiterlaufen.
