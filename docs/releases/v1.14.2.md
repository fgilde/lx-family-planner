# LX Family Planner 1.14.2

Dieses Wartungs- und Datenschutzupdate liefert die neutrale Familienanmeldung
über den abgesicherten Docker-Updateweg aus.

## Änderungen

- Das öffentliche Feld „Familienname“ nennt keinen echten Familiennamen als
  Beispiel.
- Docker erhält nur `CHOWN`, `SETGID` und `SETUID`, um eingebundene Datenordner
  vor dem Wechsel zum unprivilegierten App-Benutzer vorzubereiten.
- Der Sicherungs- und Prüflauf vor Updates funktioniert damit wieder.
- Plattformen mit bereits passenden Ordnerrechten können LX weiterhin ohne
  zusätzliche Root-Rechte starten.
- Ein Regressionstest schützt sowohl die neutrale Anmeldung als auch den
  Docker-Updateweg.

Familienkonten, Passwörter, Profile, Einstellungen und gespeicherte Inhalte
bleiben unverändert.

---

LX Family Planner 1.14.2 ships the anonymous login copy through the protected
Docker update path and preserves all existing family data.
