# LX Family 1.18.3

## Sicherer Umgang mit alten Sicherungen

Dieses Server-Hotfix macht den letzten Schritt eines Updates robuster:

- Die Sicherungsbereinigung wird in einem frischen LX-Container ausgeführt,
  damit Besitzrechte aus älteren Installationen repariert werden können.
- Bestand ein Update bereits den Gesundheits- und Datencheck, bleibt es aktiv,
  selbst wenn einzelne alte Sicherungen nicht entfernt werden können.
- In diesem Ausnahmefall löscht LX nichts: Alle vorhandenen Sicherungen bleiben
  erhalten und die Bereinigung wird beim nächsten erfolgreichen Lauf erneut
  versucht.

Familien, Profile, Termine, Aufgaben, Rezepte, Dateien und Einstellungen
bleiben unverändert erhalten.
