## 1. Home Assistant Community – *Share your Projects!*

**Titel:** LX Family – a self-hosted family board with calendars, chores, kid profiles and Home Assistant widgets

**Beitrag:**

Hi everyone,

I built **LX Family**, a private, self-hosted Family OS for the screen that is
actually shared at home: the kitchen tablet, a wall display, a browser and the
family phones.

The idea is to keep shared calendars, task approvals, shopping, meal planning,
recipes, chat and family files in one place. Adult profiles get planning and
admin tools; children get an age-appropriate, playful view with routines,
missions and rewards. There are also reduced pet profiles for care and health
reminders only.

For Home Assistant users, LX Family can show chosen HA entities as dashboard
widgets and optionally allow the controls you explicitly enable. It is useful
for a kitchen tablet where the next appointment, a chore and a smart-home tile
should sit next to each other instead of in separate apps.

**Available now:** Docker, Proxmox, Unraid Community Applications and a native
Android APK. The Umbrel submission is in review. LX Family is MIT-licensed and
has no hosted service or telemetry – each household runs its own instance.
The interface is available in seven languages: German, English, French,
Spanish, Italian, Dutch and Polish.

- GitHub and installation: https://github.com/laxxx-lab/lx-family-planner
- Read-only demo: https://familie.laxxx-lab.de/ – family **Demo**, password
  **demo**. It is a shared showroom; please do not enter personal data.
- Screenshots: dashboard, child profile and tablet mode are at the top of the
  README.

I would especially value feedback from people using a tablet or wall panel with
Home Assistant: which small, family-safe HA widget would make this useful every
day?

**Transparency:** Both LX Family and this post were created with AI as a tool.
Product direction, testing, release decisions and ongoing maintenance remain
the maintainer's responsibility.

## 2. Reddit r/unRAID

**Titel:** LX Family – private self-hosted Family OS now available through Community Applications

**Beitrag:**

I built **LX Family**, a self-hosted family hub for shared calendars, chores,
shopping, meal planning, recipes, chat, family files and kid-friendly profiles.
It is now available through Unraid Community Applications.

What makes it different from a generic dashboard: kids have their own playful
space with routines, missions and adult-approved rewards; parents keep the
planning and administration view; pet profiles only expose care-related parts.
There is an optional Home Assistant dashboard integration, Nextcloud family
archive, Bring!, Gotify and ntfy.

It runs as a normal, unprivileged container with persistent data and backups.
Existing data survives updates; the project includes a documented backup and
rollback path.

The interface is available in seven languages: German, English, French,
Spanish, Italian, Dutch and Polish.

- GitHub / docs: https://github.com/laxxx-lab/lx-family-planner
- Read-only demo: https://familie.laxxx-lab.de/ – family **Demo**, password
  **demo**. It is a shared showroom; please do not enter personal data.
- Android APK and Docker/Proxmox installation are in the README.

I would love feedback from Unraid families: is there a dashboard tile,
integration or backup workflow that you would want before trusting it for daily
use?

**Transparency:** Both LX Family and this post were created with AI as a tool.
Product direction, testing, release decisions and ongoing maintenance remain
the maintainer's responsibility.
